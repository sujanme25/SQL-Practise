# SQL Practice Repository

## Overview

This repository contains a structured collection of **100 SQL practice questions and solutions** designed to help learners build strong SQL fundamentals and progress to advanced, interview-level problem solving.

The exercises are based on a realistic database consisting of **Employees, Customers, Products, and Orders** tables and cover a wide range of SQL concepts used in data analytics, business intelligence, reporting, and database development roles.

Whether you are learning SQL for the first time, preparing for technical interviews, or sharpening your analytical skills, this repository provides hands-on practice through progressively challenging exercises.

3. Attempt Questions 51–100
