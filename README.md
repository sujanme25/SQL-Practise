# SQL Practice Repository

## Overview

This repository contains a structured collection of **100 SQL practice questions and solutions** designed to help learners build strong SQL fundamentals and progress to advanced, interview-level problem solving.

The exercises are based on a realistic database consisting of **Employees, Customers, Products, and Orders** tables and cover a wide range of SQL concepts used in data analytics, business intelligence, reporting, and database development roles.

Whether you are learning SQL for the first time, preparing for technical interviews, or sharpening your analytical skills, this repository provides hands-on practice through progressively challenging exercises.

### Real-World Scenarios
 
Questions 101–120 include practical business problems such as:
 
- Determining manager and employee hierarchies
- Identifying top revenue contributors
- Detecting customer purchasing patterns
- Measuring month-over-month growth
- Calculating moving averages
- Finding purchasing gaps and customer inactivity periods

- Building comprehensive customer analytics dashboards

These challenges are intended for learners preparing for advanced SQL interviews, data analyst roles, business intelligence positions, and real-world reporting environments.
## Recommended Learning Path

1. Complete Questions 1–25
2. Progress through Questions 26–50
3. Attempt Questions 51–100
4. Optimise your solutions
5. Try alternative approaches using JOINs, Subqueries, CTEs and Window Functions
